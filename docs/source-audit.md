# Source Visual Audit

## Shared visual system

The source uses a premium editorial real-estate presentation: deep navy hero and navigation surfaces, a restrained champagne-gold accent, pale mist content backgrounds, white cards, Cormorant display typography, and Inter interface/body typography. Primary calls to action are compact rectangular buttons rather than pill buttons. The layout is spacious, with strong horizontal containers, an opaque/light scrolled navigation state, and thin gold eyebrow rules.

## Homepage

The source homepage begins with a cinematic cityscape/video hero under a translucent dark navigation bar. Its content rests low within the hero, pairing an oversized multi-line serif statement with restrained supporting copy, two calls to action, and a small service-positioning label. It alternates navy, white, and mist sections for service cards, a dynamic featured-listing region, a numbered process section, a closing consultation panel, and a large multi-column footer.

## Property listing page

The listings page uses a navy introductory header, followed by a white, sticky filter region with segmented listing/type controls and simple select fields. Result cards sit on a mist background and use white surfaces, subtle borders, crisp listing tags, large property imagery, compact metadata, and a decorative but content-rich footer. The source shows an empty/loading state when there are no approved public records.
